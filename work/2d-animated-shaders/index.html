2D Animated Shaders

2D animated shaders are operated by only pixel shader (I was inspired by golden card effect in hearthstone). I used simple techniques in pixel shader as rotation, divided layer for background, UV distortion and scaling, etc.

These portraits were applied for Battle-Pet system in TERA.
