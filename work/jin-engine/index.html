Jin Engine

Jin Engine is a private rendering engine.

The goal of this project is to broaden knowledge what I have studied and to refine the State-of-the-art computer graphics techniques in the future.

GitHub repo

  • DirectX11 build

Key features

  • Physically-based rendering
  • CubeMap Mip for Global Illumination
  • VXGI (Voxel Global illumination) (Working…)
  • VR mode (Working…)
  • Light Bloom
  • Screen Space Reflection (Working…)
  • Lens flare
  • Depth of Field
  • HBAO
  • Anti-Aliasing (Working…)
  • Shadow Map (Working…)
    • LogPSM
    • Cascade Shadow
    • Sample Distribution Shadow Maps
    • Variance Shadow Maps
