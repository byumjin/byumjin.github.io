The Last Mutant

This project is for 2012 Indie Game Competition in South Korea. (when I was a undergraudate student.)

The purpose of game design is that we want to create MOBA with Third-person action such as Arena in World of Warcraft. The number of involved people was four, and I took the parts of client programming and game design. We used Unity3D engine and had made this game for 2 months. The obejective of this game is to kill enemies 10 time first or annihilating all enemies. Each player can select one mutant among six mutnats. Players can attain EXP when they hunt neutral monsters or kill enemies. When their level is up, they can use new skills. This game only supports On-line battle mode.
